1. 原有每小时官网同步任务继续运行，未另建任务。管理员也可在俱乐部工作区点击“同步官网”或赛事详情中的“检查这场比赛更新”。
2. 服务器先读取 Skate Ontario 官方日历，范围约未来 183 天；详细资料优先检查未来 45 天内最近三场比赛。日历成功不等于每份文件均已读取。
3. 解析已支持的报名名单、带明确日期和冰场表头的赛程 PDF、Starting Order；保留原始链接、检查时间和文件哈希。同链接文件内容修订也能被识别。
4. 结构化资料保存到原 D1 的 `live_events`，变更与通知 outbox 原子写入。教练备注、集合时间和私人关系分别保存，不由官网同步覆盖。
5. 网页通过 `/api/club` 读取已保存资料，按当前账号权限过滤私人安排，再显示赛程、选手和来源。
6. 所有已获准查看赛程的用户都可“重新读取资料”，只读取数据库最新版本，不抓取官网。管理员的“同步官网”才会发起新的来源检查；服务端管理员及写入来源校验仍保留。

网页显示最近日历读取成功、最近来源检查尝试，以及同步错误。失败保留上次有效资料，未识别格式保留链接并标待核对；未知个人时间和热身组不自行推算。不是实时推送，不承诺覆盖所有官方格式；Skate Canada 自动同步尚未实现。
