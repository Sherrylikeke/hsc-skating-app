| C02 | 产品与视觉 | 保留原站栏目、层级、功能和主要操作习惯，重点改善外观；后台未知功能仍须核验 |

| C04 | 前端 | 沿用 TypeScript、React、Tailwind、当前 Next 路由体系与 Vinext／Vite 构建 |
| C05 | 后端 | 沿用现有 Cloudflare Worker；托管方式已确认继续由 Sites 管理，具体部署与交接安排另定 |
| C06 | 数据库 | 沿用 D1 和 Drizzle；保留原数据，只追加业务表与增量迁移 |
| C07 | 内容管理 | 应用内轻量后台，Board 使用现有账号并按服务端内容权限操作；独立 CMS 比较后未采用 |

| C12 | 托管方式 | 沿用当前 Sites 托管，复用既有项目及 Worker／D1；本次不规划迁至俱乐部或个人独立 Cloudflare 账号。R2 实际绑定、部署流程及 Board 交接仍待核实 |
| C13 | 首页与会员入口 | 默认打开俱乐部官网首页，保留原官网栏目；现有比赛赛程通过会员入口进入。原官网 Schedule 仍指课程课表，与比赛赛程明确区分；具体路径及旧链接兼容另行设计 |
| C14 | 品牌与配色方向 | 保留 HSC 现有 Logo，重新探索网站配色，不要求沿用原主色；原栏目、功能和主要操作流程保持不变。具体色板、字体及页面视觉方案尚未选定，后续通过代表页面比较 |
| C15 | 内容发布流程 | 已获内容权限的编辑可直接发布网页文字、公告等内容，不要求另一位管理员审核后才能发布。权限由服务端控制；不因此授予收费操作、会员私人资料或权限管理能力。此项解决原 P10，旧后台流程仍未核验 |
| C16 | 上线切换方式 | 官网、报名和付款全部完成并验收后统一切换，不采用官网先上线、报名付款随后迁移的分段上线方案。此项解决原 P11；具体日期、后台核验、数据与财务核对、迁移演练及切换执行另行落实，本次仅确认规划方向 |
| C17 | 旧会员首次登录 | 只有 Uplifter 账号的旧会员迁移后通过邮件激活并设置新密码；已有 HSC 应用账号及其登录方式保留。账号匹配、重复账号处理和家庭关系另行核验；邮箱激活本身不授予私人关系或管理权限，实际激活邮件尚未发送 |
| C18 | 轻量备份与运维 | 用户同意备份方向，并要求适合低维护非营利组织、减少保留量与运维负担。按此采用 v1 默认：优先平台自带恢复，每周独立加密备份保最近 4 份，重大更新前额外备份；只网站不可用／备份失败提醒，上线前一次恢复验证，重大变更或交接时再验证。具体周期为按用户简化指示作出的实施默认；平台权限、独立存储及实际执行尚待接通 |

C01 至 C08 在 2026年11月18日讨论确认；C09 至 C18 在 2026年11月19日确认。选型结果不表示对应功能已经开发、部署或验收；实际状态见新版 PRD、v1 验收记录及项目 Note。
