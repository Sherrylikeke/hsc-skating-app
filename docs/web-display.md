# 网页资料展示

## 参考资料

官网检查流程、检查时间、批次进度和原始解析错误集中放在工作区各页面末尾的“参考资料 · 数据来源与同步详情”，默认收起；切换页面或选手后重新收起。选手档案和赛程优先展示，不再被技术卡片挡住。资料、同步规则与管理员权限未修改。实际时段的不确定标记、候选时段和官方来源链接继续保留，不因收纳技术说明而伪称数据完整。

## 成绩总趋势

成绩趋势默认“全部类别 · 总趋势”，展示当前筛选下所有有效成绩的时间分布。不同类别和成绩口径分别连线，以颜色、图例和数据点提示标识；不把不同类别接成一条同口径曲线，不相加或计算混合总分。跨类别原始分数不一定可直接比较。

仍可选择单一类别/口径，此时保留该序列的最佳、最近成绩。总览只统计成绩条数与序列数量，不把跨类别最高分当作同类别个人最佳。赛季、项目、口径、比赛、状态、搜索等筛选继续同时作用于图表与下表；重置筛选回到全部类别。点击任意成绩点仍查看原始记录。

退赛、仅名单/出场顺序、缺失/空白/非法分数及团体成绩不画入个人趋势；真实零分保留。图中同类别多个赛季的数据仍按实际日期排序。没有成绩时显示原空状态。

## 教练总表比赛筛选

教练总表增加独立比赛筛选，默认“全部比赛”。选定比赛后可继续叠加负责教练、日期、仅已分配教练；切换比赛清空旧日期，避免前一场日期造成误导的空表。重置恢复全部比赛/全部教练/全部日期和默认仅已分配。表格、人数统计与 CSV 导出使用同一份筛选结果；待重新核对的旧教练安排也按比赛过滤，不修改保存内容。没有读取成功或匹配时段的赛事仍可以选择，但不会虚构表格行。

验证：`node scripts/check-athlete-history.mjs` 包含全部/单类/过滤/空数据、原始记录数以及 Fiora 的服务端图表渲染；同时检查参考资料位于内容后、页脚前且默认收起。`node scripts/check-coach-schedule.mjs` 验证赛事、日期、多个教练的交集、空结果和表格/导出一致。另运行 Web 类型、语言与相关客户端回归并构建后私人发布。
