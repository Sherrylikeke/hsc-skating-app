## 参考资料

2026-10-26 补充：`/api/club` 按服务端实际角色投影响应。普通会员、家长、选手、教练及非有效管理员只收到比赛/名单/时段/出场信息的白名单字段、官方链接及 `needsReview` 布尔标志；不返回原始错误、检查时间、导入状态/批次、哈希、解析器版本及嵌套 `entryFiles`。有效管理员仍保留完整来源诊断。界面待核对提示使用标志，不再依赖原始错误；主内容的出场状态按已发布记录显示简短中英说明。数据库原始存档、私人权限和同步写入规则未改变。

2026-10-24 补充：普通会员不渲染来源诊断 Reference。比赛详情顶部不再展示报名批次、PDF 文件名、原始解析错误及检查时间；只在资料待核对时保留简短提示和官方文档链接。有效管理员可在页面末尾默认收起的“管理员参考资料 · 来源诊断”查看全局状态、逐场状态和文件进度。管理员手动同步部分失败仍明确提示，不将失败伪装成成功，也不在主内容重复原始错误。此为展示收纳，不代表 API 数据字段已做额外脱敏。

官网检查流程、检查时间、批次进度和原始解析错误集中放在工作区各页面末尾的“参考资料 · 数据来源与同步详情”，默认收起；切换页面或选手后重新收起。选手档案和赛程优先展示，不再被技术卡片挡住。资料、同步规则与管理员权限未修改。实际时段的不确定标记、候选时段和官方来源链接继续保留，不因收纳技术说明而伪称数据完整。

## 单类别成绩趋势

按用户 2026-10-23 的最新要求，移除“全部类别 · 总趋势”和混合图例。图表每次只展示相同类别与成绩口径；默认选择有成绩的一个类别，可通过原下拉选项切换，不跨类别连线或比较。

保留所选序列的最佳、最近成绩。赛季、项目、口径、比赛、状态、搜索等筛选继续作用于历史资料与图表可选类别；重置筛选回到默认单类别。如果原序列不在新筛选结果中，选取剩余有效类别，不退回混合视图。点击任意成绩点仍查看原始记录。全部历史记录保留在下表，没有删除成绩数据。

按用户随后要求，类别改用大类：Group/Grp 分组、NQ/Non-Qualifying、重复 STAR 前缀及括号写法归并，显示如 STAR 5 U10、STAR 7 U12。选手卡片、档案简介、历史类别筛选和趋势使用同一套展示分类。保留年龄上下限、Short/Free、Artistic、Class、性别和成绩口径的区别；单人档案标签通常省略性别，若同一列表同时出现男女类别则恢复性别标识，避免重名合并。没有明确年龄的 Pre-Juvenile 不猜作 U11。

同一选手、同一自然年内，如果 Pre-Juvenile 有唯一的明确年龄类别，则把未标年龄的 Pre-Juvenile 归入该类别。不同年份、不同选手、多个冲突年龄、多选手身份或不同项目不推断；同一滑冰赛季跨年也不跨年套用。筛选比赛或日期后仍用完整档案作为归类上下文，避免选中一场比赛时类别忽然拆开。

原始类别、成绩、日期、名次和来源完全保留。Fiora 的 17 条有效成绩归为 3 个趋势序列：STAR 5 U10 为 9 条、STAR 7 U12 为 5 条、Pre-Juvenile U11 为 3 条；历史筛选还有无分数的 STAR 2、STAR 4 U10。没有恢复全部类别混合趋势，赛程及出场顺序匹配不使用这套展示归并规则。

退赛、仅名单/出场顺序、缺失/空白/非法分数及团体成绩不画入个人趋势；真实零分保留。图中同类别多个赛季的数据仍按实际日期排序。没有成绩时显示原空状态。

## 教练总表比赛筛选

教练总表增加独立比赛筛选，默认“全部比赛”。选定比赛后可继续叠加负责教练、日期、仅已分配教练；切换比赛清空旧日期，避免前一场日期造成误导的空表。重置恢复全部比赛/全部教练/全部日期和默认仅已分配。表格、人数统计与 CSV 导出使用同一份筛选结果；待重新核对的旧教练安排也按比赛过滤，不修改保存内容。没有读取成功或匹配时段的赛事仍可以选择，但不会虚构表格行。

## 教练维护页返回与访问

`/coaches` 顶部新增返回教练总表、返回我的主页的明确链接，原未保存修改保护与草稿保留不变。该页只允许有效管理员；普通教练、家长、选手和只读会员不是管理员，不能进入维护页。原 GET/POST API 已做管理员校验，现在页面服务端也先检查实际会话和角色，再决定是否渲染编辑器；401/403 返回会员主页，其他服务错误不冒充无权限。登录失效时编辑器也引导至原会员入口，不提供旧 ChatGPT 专用登录按钮。

验证：`node scripts/check-athlete-history.mjs` 包含同选手同年归并、跨年/冲突年龄/不同身份拒绝推断及筛选上下文稳定性。`node scripts/check-members.mjs` 在隔离数据库实际运行页面与 API，验证普通角色不可访问、管理员可进入及返回入口存在。`node scripts/check-coach-schedule.mjs` 继续验证比赛筛选。另运行 Web 类型、语言与相关客户端回归并构建后私人发布。
